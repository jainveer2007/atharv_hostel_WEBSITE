# Atharv Residency

A modern, responsive hostel management and student accommodation website built with React and Vite.

## Features

- **Home Page**: Interactive accommodation showcase highlighting Single Bed, Double Bed, and Triple Bed options with complete amenity details.
- **About Us Page**: Overview of management, key metrics, and campus life showcase.
- **Contact Us Page**: Inquiry form with real-time feedback, campus office location, and direct helpline contact details.
- **Modern Design**: Dark glassmorphic theme with warm amber accents, custom typography, and responsive layouts for desktop and mobile.

## Tech Stack

- [React 19](https://react.dev/)
- [Vite](https://vite.dev/)
- [React Router](https://reactrouter.com/)
- [Tailwind CSS](https://tailwindcss.com/)

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
```
